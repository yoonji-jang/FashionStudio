# 영상 기준

코디 주제 하나당 영상 한 편 (profile `video`). 컨셉을 짤 때(video-concept 스킬) 이 기준을 따른다.
계정에 맞게 고쳐 쓴다. 예시는 accounts/women/video.md.

## 목적
- 옷 제품에 관심이 가게 만드는 영상. 모델과 옷이 잘 보이는 것이 가장 중요하다.

## 공통 규칙
- 화면에는 모델 한 명만. 여러 벌 모두 같은 배경, 같은 얼굴.
- 카메라는 멈춰 있고 구도도 바뀌지 않는다. 움직이는 건 모델뿐.
- 전신이 항상 화면 안에.
- 동작은 간단하게 (걷기, 가벼운 춤). 동작 컨셉은 여러 벌이 통일한다.
