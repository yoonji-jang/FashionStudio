# 말투 가이드: 여성 데일리 코디

제목·캡션·해시태그를 쓰는 스킬(write-copy)이 이 파일을 그대로 따른다. 사람이 가끔 고치는 곳.
글자 수, 해시태그 개수, 기본 해시태그, 금지 표현, 고지 문구 같은 숫자·목록은
`profile.yaml` 의 `copy` 에 있고 `tools.plan check` 가 자동으로 검사한다.

## 말투 (2026-09-30 14단계에서 A 톤 + 이모지 조금으로 정함)
- 친한 언니가 알려주는 느낌의 부드러운 존댓말 (~해요, ~보세요). 반말은 쓰지 않는다
- 짧고 담백하게. 느낌표는 캡션 전체에서 1개까지
- 이모지는 과하지 않게 곁들인다
  - 도입 한 줄과 코디 포인트에 합쳐 3개까지, 한 줄에 하나, 문장 끝에만
  - 코디 포인트 3줄 중 1줄은 이모지 없이 둔다 (전부 달면 과해 보임)
  - 그 줄의 색·계절·분위기와 맞는 것: 🍂 🍁 ☕ 🖤 🤍 🤎 🍷 🧥 👜 👟 ✨ 🌙 ☔ 등
  - 얼굴 이모지(😍🤣)나 같은 이모지 반복은 쓰지 않는다
  - 표지 제목, 상품 장 이름·코멘트에는 쓰지 않는다 (이미지 안 글자)

## 커버 제목 (2줄)
- 줄당 8~18자
- 두 줄을 합쳐 "이게 어떤 코디인지" 한 문장으로 설명하는 느낌 (2026-10-01 사용자)
- 이 코디만의 포인트 하나가 꼭 들어간다. 사진을 보면 바로 보이는 것으로 구체적으로 쓴다
  - 색 조합: 브라운에 버건디 한 방울, 그레이 위에 크림색
  - 소재·질감: 스웨이드, 레더, 꽈배기 니트, 광택 새틴
  - 입는 방법: 셔츠 깃만 빼기, 소매 걷기, 어깨에 두르기, 넣어 입기
  - 실루엣·디테일: 크롭 기장, 와이드 핏, 금장 버튼, 스티치
  - 소품 한 끗: 실버 주얼리, 스카프, 앵클부츠
- 아이템 이름만 말하는 제목은 쓰지 않는다 ("가디건 걸친 룩", "무채색으로 단정하게" 처럼 어느 날에나 붙는 말)
- 요일은 넣지 않는다 ("월요일 출근룩" 대신 "출근룩"). 금지 목록은 profile `copy.title_banned`
- 참고 계정 문구를 그대로 쓰지 않는다

### 여러 벌 게시물 표지 (profile `looks`, 2026-10-01 사용자 피드백)
- 한 벌이 아니라 그날 여러 벌 전체를 묶는 제목. 계절·날씨·상황에 맞춘 **코디 추천 모음집** 느낌으로 쓴다
  (환절기, 일교차 큰 날, 출근룩·약속룩 처럼 언제 입을지가 보이게)
- 벌 수는 쓰지 않는다 ("여섯 벌", "6가지 룩" ✗). `tools.plan check` 가 막는다
- 예: 일교차 큰 날 출근룩부터 / 약속룩까지 가을 코디 모음
- 예: 아침저녁 쌀쌀한 환절기 / 아우터 하나로 완성한 코디
- 예: 출근부터 저녁 약속까지 / 간절기 데일리룩 모음
- 아래 한 벌용 스타일(A~F)은 여러 벌에도 쓸 수 있지만, 한 벌의 포인트보다 묶는 주제를 앞에 둔다

### 모델컷 게시물 표지 (profile `model_shot`, 2026-10-07 사용자)
- 펼친 코디컷 게시물과 똑같이 **코디 모음** 제목으로 쓴다. 사람이 입은 사진이라는 점이나 전날 게시물을 말하지 않는다
- 쓰지 않는 말: "어제 그 코디", "입으면 이런 느낌", "직접 입어 보니", "모델컷", "착용샷"
- 예: 브라운 스웨이드로 채운 / 가을 데일리룩 모음
- 예: 쌀쌀한 아침부터 저녁 약속까지 / 니트 코디 모음

### 제목 스타일 (골고루 섞어 쓴다)
아래 여섯 가지를 돌려 가며 쓴다. 최근 게시 제목(`tools.plan context` 의 최근 게시)과 같은 스타일이
이틀 연속되지 않게 고른다. 코디에 가장 잘 맞는 스타일을 먼저 본다 (대비가 뚜렷하면 D, 입는 방법이 포인트면 A).

- **A. 한 문장으로 이어지는 설명**: 무엇을 어떻게 입은 무슨 룩인지
  - 레더자켓 안에 흰 셔츠 받쳐 / 딱딱함을 푼 출근룩
  - 크림 가디건을 어깨에 둘러 / 포근하게 마무리한 데님룩
  - 트렌치 소매를 걷어 올려 / 가볍게 입은 주말룩
- **B. 무드 + 룩 이름**
  - 시크하지만 단정한 / 레더자켓 오피스룩
  - 포근하고 여리한 / 아이보리 니트 데이트룩
  - 차분하고 깔끔한 / 네이비 셔츠 출근룩
- **C. 이 룩은 한마디로**: 포인트 + 룩 이름
  - 흰 셔츠로 힘을 뺀 / 올블랙 레더룩
  - 브라운 하나로 통일한 / 톤온톤 가을룩
  - 스니커즈로 반전 준 / 롱스커트 브런치룩
- **D. 소재나 색 대비**
  - 거친 레더에 / 매끈한 셔츠 한 장
  - 까슬한 트위드에 / 부드러운 새틴 스커트
  - 차가운 그레이에 / 따뜻한 카멜 코트
- **E. 상황 + 완성된 룩**
  - 쌀쌀한 출근길엔 / 레더자켓에 셔츠 한 장
  - 선선한 저녁 약속엔 / 버건디 니트에 롱스커트
  - 비 오는 날엔 / 트렌치에 레인부츠 셋업
- **F. 누가 입으면 좋은지**
  - 출근룩이 심심한 분께 / 레더자켓 셔츠 레이어드
  - 키가 작아 고민이라면 / 크롭 가디건 하이웨이스트
  - 꾸안꾸가 어려울 때 / 니트 한 장에 실버 링

### 피할 제목 (평범하거나 요일이 들어감)
- 비 오는 수요일 출근길엔 / 무채색으로 단정하게
- 가을엔 가디건 / 걸치기만 해도 예뻐요
- 월요일 출근룩은 / 네이비 하나면 충분해요

(실제 반응 좋은 제목을 스타일별로 더 채운다)

## 캡션 구조
스킬은 2번(도입)·3번(코디 포인트)과 해시태그만 쓰고, 나머지는 tools.plan 이 profile 문구로 붙인다.
1. (monetize가 manual_link일 때만) 첫 줄 광고 고지
2. 도입 한 줄: 그날 날씨·요일·상황을 열고 오늘 아이템을 권한다. 피드에서 먼저 보이는 줄
3. 코디 포인트 3줄: 한 줄에 한 가지 (색 조합, 핏, 소재, 입는 방법)
4. 제품 목록: 쇼핑몰 · 상품명
5. 링크 안내 (댓글 DM이 켜져 있으면 `comments.cta`, 아니면 `copy.link_line`)
6. AI 고지: "이미지는 AI로 합성했으며 실제 색감·디테일과 다를 수 있어요"

## 상품 장 문구
- 짧은 이름: 광고 문구·품번 없이 색 + 특징 + 종류 (예: 블랙 싱글 레더 하프자켓)
- 코멘트: 한두 문장, ~해요 존댓말. 이 코디에서 이 상품이 하는 역할이나 입는 팁. 이모지 없음
  (예: 아침저녁 쌀쌀한 날 가볍게 걸치기 좋은 차콜 롱코트예요.)

## 해시태그
- 10~15개. monetize가 manual_link면 첫 해시태그는 반드시 #광고
- 기본 묶음(profile `copy.base_hashtags`)은 자동으로 붙으니, 주제·아이템·상황 해시태그만 더 쓴다

## 금지 표현
- 체형 비하 ("뚱뚱해 보이는", "하체 비만 커버")
- 과장 ("무조건", "100% 인생템", "역대급")
- 가격 단정 ("최저가")
- 다른 계정·브랜드 비방
