# 후보 고치기 (2026-10-22, run339)

- 1번: 블랙 레더벨트(아이콧 베이직 레더벨트) 추가.
- 2번: 메리제인 플랫 → 블랙 스퀘어토 슬링백힐(모비나 스퀘어 슬링백힐). 창고에 블랙 스퀘어·뾰족 로퍼가 없어 구두로 맞춤.
- 4번: 가디건 → 블랙 골지 크롭 가디건, 와이드 슬랙스 → 블루 워싱 부츠컷 데님(프랭키 와이드부츠컷), 슬라우치 부츠 → 뾰족코 슬링백.
  창고에 로우라이즈 + 부츠컷을 동시에 갖춘 청바지가 없어 부츠컷 데님으로 맞춤 (허리는 낮게 입히도록 desc 에 적음).
- 6번: 레이어드 니트 → 골지 브이넥 가디건(더 깊은 브이), 스트라이프 풀오버 → 장식 없는 스트라이프 티(이든 스트라이프 티셔츠, 차콜),
  앵클부츠 → 스니커즈 로퍼(굽이 있는 낮은 스퀘어토). 이너 스트라이프 경고는 사용자 요청이라 그대로 둠.
- 7번: 그레이 캐미 → 그레이 레이스 나시(벨리스 레이스 나시, 그레이 색상 있음).
- 8번: 와이드 레더 벨트(켄달 와이드 스퀘어 버클) 추가.
- 10번: 슬랙스 → 슬림 부츠컷 슬랙스, 신발 → 뾰족코 스틸레토 슬링백, 실버 목걸이·귀걸이 추가.
  **상의는 그대로**: 창고에 드레이프 오프숄더 상품이 없어 기존 원 오프숄더 니트를 유지함.
- 11번: 슬림 골드버클 벨트 추가.
- 나머지 벌(3, 5, 9)과 순서·theme·전체 reason 은 그대로.
