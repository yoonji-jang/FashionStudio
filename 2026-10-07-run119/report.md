# 2026-10-07 코디 후보 (women, outfit-candidates)

## 주제
[컬러무드] 브라운에 하늘색 한 방울, 가을 컬러 조합. 수요일, 서울 맑음 13~22°C라 셔츠·니트 레이어드가 알맞음.
여러 벌 게시물(looks.enabled)이라 `picks/p1.yaml` 하나에 8벌(앞 6벌 + 예비 2벌). 7·8번이 예비.
`COLLECT` 없음: 새 수집 없이 창고 상품만 썼고, 지난 후보(`previous/`)도 없음.

## 벌
1. 스웨이드 자켓(브라운) + 하늘색 스트라이프 셔츠 + 아이보리 와이드 데님. 주제 정석, 쁘띠 스카프 포인트
2. 코듀로이 자켓(네이비) + 브라운 니트 베스트 + 하늘색 셔츠 깃 빼기 + 아이보리 플리츠 롱스커트
3. 모헤어 가디건(브라운) + 하늘색 스트라이프 셔츠 + 연청 와이드 데님 + 볼캡
4. 아이보리 케이블 가디건 + 하늘색 헨리넥 + 스웨이드 미니스커트(브라운) + 니삭스 (실루엣 대비)
5. 스웨이드 블루종(브라운) + 하늘색 헨리넥 + 그레이 핀스트라이프 슬랙스 + 가죽 벨트
6. 아우터 없이 브라운 니트 조끼 + 하늘색 셔츠 + 베이지 와이드 슬랙스 + 쁘띠 스카프
7. (예비) 크롭 스웨이드 집업(브라운) + 하늘색 셔츠 + 딥 인디고 데님 + 슬림 벨트
8. (예비) 브라운·하늘색 스트라이프 가디건 + 아이보리 헨리넥 + 브라운 새틴 미디스커트 + 쁘띠 스카프

## 확인할 것·경고
- `tools.plan check --draft` 통과. 남은 경고는 소품(스카프·귀걸이·볼캡·니삭스)에 `slot`·`wear_with` 가 없다는 것뿐이다. 생성형 코디컷에는 영향이 없다 (누끼 방식 전용 안내).
- 색은 상품명과 옵션 표기로만 골랐고 사진은 보지 않았다. 사진 확인 단계에서 고른 색 옵션이 없으면 같은 카테고리의 비슷한 상품으로 바꿔야 한다.
  특히 확인이 필요한 것: 1번 아이보리 데님(171292012), 4번 블랙 메리제인 대신 브라운 쪽 선택 여부, 6번 베이지 슬랙스(135443091), 7번 딥 인디고 데님(171322447).
- 스웨이드 아우터가 1·5·7번에 있고 4번은 스웨이드 스커트라, 소재가 비슷한 벌이 여럿이다. 주인공 상품과 형태(자켓·블루종·크롭 집업·스커트)는 모두 다르다.
- 가방·신발·소품은 벌마다 다른 상품이다. 같은 상품은 한 번씩만 썼다.
- 상의 레이어 `wear_with` 는 3·4·8번이 아우터, 2·6번이 상의 기준이다.
