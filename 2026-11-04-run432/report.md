# 2026-11-04 코디 후보 (candidates)

주제: 연말 코디 (송년회·크리스마스 약속, 따뜻하고 분위기 있는 룩). 정해 둔 주제 사용, COLLECT=1 로 검색어 6개 수집 (새 상품은 소품 9개뿐).
`picks_request.json` 없음 → 평소 흐름. 여러 벌 게시물이라 `picks/p1.yaml` 하나에 8벌(6+예비 2).

## 사람 확인 필요 (스킬 기준과 다르게 한 곳)
- **4벌 더 짜서 점수로 거르는 4-1 단계를 하지 못함**: 8벌만 짰고 8점 미만도 그대로 보냄. 점수는 ref 사진 없이 칸 글로만 매김
  (참고 사진 대부분이 텔레그램 사진 `tg:` 이거나 받지 않음).
- 참고 코디 7개(778, 117, 157, 174, 249, 256, 158) + 참고 없이 주제 기준으로 짠 8번(예비).
- 창고 상품 사진 색이 참고 칸과 달라 대체한 곳은 아래.

## 벌
1. 블랙 트위드 자켓 + 그레이 헨리넥 + 네이비 울 미니 + 플랫폼 메리제인 + 니삭스 + 체인백 (참고 778) [7] — 프릴 미니·도트 스타킹 없음
2. 블랙 울 롱코트 + 모카 브라운 브이넥 니트 + 새틴 롱스커트 + 숄더백 + 발레리나 (참고 117) [7] — 블랙 니트 사진 없어 니트만 브라운
3. 퍼플 울 가디건 + 헨리넥 + 블랙 벨벳 미디 + 발레리나 + 롱 목걸이 + 레더백 (참고 157) [8] — 참고는 모헤어 니트, 창고는 울 가디건
4. 네이비 카디건 + 그레이 캐미 + 차콜 울 미니 + 앵클부츠 + 니삭스 + 숄더백 (참고 174) [7] — 블랙 카디건·레이스 캐미 없음
5. 아이보리 리본 블라우스 + 새틴 롱스커트 + 에나멜 슬링백 + 리본 핀 + 체인백 (참고 249) [8] — 슬릿 없음
6. 차콜 오프숄더(셔츠카라 일체형) 니트 + 차콜 울 미니 + 버클 롱부츠 + 체인백 + 롱 목걸이 (참고 256) [7]
7. 라이트 그레이 아가일 카디건 + 그레이 캐미 + 블랙 코듀로이 미디 + 버클 롱부츠 + 미니 숄더백 (참고 158) [7] — 차콜 벨벳 레이스 스커트 없어 코듀로이로 대체
8. 그레이 스카프 리본 블라우스 + 블랙 새틴 맥시 + 앵클스트랩 펌프스 + 링 귀걸이 + 미니 체인 백팩 (참고 없음, 예비) [7]
