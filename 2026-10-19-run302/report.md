# 코디 후보 보고 (women, 2026-10-19)

주제: [아이템] 롱스커트 하나로 끝내는 가을 코디 (차분한 가을 톤, 길게 떨어지는 실루엣). 모든 벌에 롱스커트를 넣음.

결과: `out/2026-10-19/picks/p1.yaml` 에 5벌. 목표(looks.count 6 + spare 2 = 8벌)에는 못 미치고 `looks.min`(5)만 채움.
`tools.plan check --draft` 통과 (경고: 소품 slot 미지정 3건, 3번 벌 목선 경고).

## 벌 (앞이 가장 자신 있는 벌)
1. [9점] 흰 슬림핏 셔츠 + 그레이 니트 맥시 스커트 + 블랙 메리제인 + 브라운 스웨이드 백 + Y라인 목걸이 (참고 316)
2. [8점] 브라운 브이넥 니트 + 아이보리 워머 티 + 크림 H라인 롱스커트 + 블랙 앵클부츠 + 브라운 스웨이드 백 + 롱 목걸이 (참고 164)
3. [8점] 그레이 하이넥 니트 가디건 + 차콜 워머 티 + 차콜 니트 맥시 스커트 + 블랙 앵클부츠 + 스웨이드 백 + 목걸이 (참고 118)
4. [8점] 아이보리 V넥 니트 + 블랙 밴딩 롱스커트 + 블랙 메리제인 + 브라운 스웨이드 백 + 롱 목걸이 (참고 319)
5. [7점, 최소 벌 수를 맞추려 넣음] 베이지 스웨이드 블루종 + 흰 셔츠 + 블랙 H라인 롱스커트 + 블랙 앵클부츠 + 블랙 백 + 큐빅 목걸이 (참고 253, 참고는 연노랑 가죽이라 소재·색이 조금 다름)

## 뺀 벌
- 참고 112 (차콜 V넥 + 홀터 탱크 + 블랙 랩 롱스커트): 맞춘 스커트가 핀스트라이프 비대칭, 홀터는 가디건 겹침 세트라 안 맞음, 확인된 대체품 없음. 점수 없이 뺌.
- 참고 171 (카키 점퍼 + 블랙 롱스커트) 7점: 사진상 카키 색이 스와치에만 있고 착용컷은 블랙·브라운 가죽·스웨이드. 8점 미만.
- 참고 210 (베이지 반팔 니트 + 브라운 롱스커트) 7점: 니트가 반팔 겹침 세트 모양이라 종류가 다름. 8점 미만.

## 알아둘 것
- 새 상품 수집(COLLECT=1)은 `tools.collect` 가 15분 넘게 응답이 없어 중단하고 창고 상품으로만 했다. 그래서 후보가 모자람.
- 날씨 예보도 못 가져옴 (SSL 시간 초과). 정해 둔 주제의 `why` 를 그대로 씀.
- 재사용 금지 기간(7일)에 걸려 참고에 있던 발레리나 플랫과 일부 가방은 쓰지 못함.
- 확인표로 색을 본 상품과 못 본 상품: 5번 벌 가방(130117567 콘라드 숄더백, 블랙으로 적음)과 목걸이 3종, 3번 벌 사라백 색은 확인표에서 확인하지 못함. 고른 뒤 사진 확인 단계에서 다시 본다.
- 참고 사진은 316·164·118·319·253 을 받아 나란히 비교했고, 나머지 참고는 refs.json 글과 확인표로만 비교했다.
- 3번 벌 "목선이 파인 상의" 경고: 차콜 워머 티를 이너(`wear_with: 아우터`)로 넣었음. 하이넥 가디건이라 실제 목선 문제는 확인 못 함.
