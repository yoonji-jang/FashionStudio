# 2026-09-28 코디 후보 (women)

## 주제
월요일 이슬비 출근길엔 가벼운 아우터로 산뜻하게 (상황)
서울 약한 이슬비, 18~24도. 어제(2026-09-27) 하프 트렌치코트 주제와 겹치지 않도록 트렌치코트는 제외하고
레더 자켓 또는 아우터 없이 셔츠·블라우스 위주로 후보를 짰다. 무채색(블랙·그레이·베이지·아이보리·네이비) 베이스에
후보별로 다른 포인트를 줬다.

## 후보
1. **블랙 오버핏 레더자켓** (에드모어) — 아이보리 셔츠 피크 + 그레이 슬랙스 + 블랙 숄더백·앵클부츠.
   가장 무난한 오피스 무드라 1번으로 뒀다 (마감까지 안 고르면 이 조합으로 진행).
2. **네이비 타이 블라우스** (슬로우리스트) — 아우터 없이 베이지 슬랙스·토트백·로퍼로 부드러운 톤, 실버 목걸이 포인트.
3. **그레이 투웨이 레더자켓** (케이클럽) — 아이보리 셔츠 피크 + 블랙 슬랙스 + 버건디 숄더백 포인트.
4. **아이보리 하이넥 셔츠** (미리내로) — 아우터 없이 네이비 슬랙스로 반반 배색, 골드 귀걸이.
5. **그레이 롱 블라우스** (디어먼트) — 아우터 없이 블랙 하프 슬랙스, 그레이 숄더백·실버 귀걸이로 무채색 미니멀.
