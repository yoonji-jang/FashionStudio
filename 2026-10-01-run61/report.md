# 2026-10-01 (목) 코디 후보 (women)

## 주제
목요일 출근길, 일교차엔 가벼운 아우터 하나로 단정하게 (상황)
이유: 서울 구름 조금, 12~20°C. 셔츠나 니트 위에 가볍게 걸치는 아우터가 알맞다. 최근 게시(트렌치, 차콜 롱코트, 무채색)와 겹치지 않게 가디건·자켓·하프코트로 잡았다. 새 수집은 하지 않았고(COLLECT 비어 있음) 창고 상품만 썼다.

## 후보 (5개, `picks/p1.yaml` … `p5.yaml`)
1. p1 — 주인공 그레이 가디건(슬로우앤드): 아이보리 셔츠 + 블랙 슬랙스·로퍼, 실버 귀걸이. 가장 안전한 조합
2. p2 — 주인공 아이보리 트위드 자켓(베니토): 블랙 하프넥 니트 + 그레이 슬랙스, 버건디 마리백 포인트
3. p3 — 주인공 베이지 울블렌디드 하프코트(미쏘): 아이보리 니트 + 진청 데님, 블랙 백·로퍼·벨트
4. p4 — 주인공 블랙 레더 자켓(가내스라): 아이보리 셔츠 + 그레이 롱스커트, 블랙 백·키튼힐 메리제인
5. p5 — 주인공 네이비 라운드 가디건(로제프란츠): 아이보리 셔츠 + 그레이 슬랙스, 버건디 토트백 포인트

주인공 상품과 주 색 조합은 모두 다르다. 같은 상품은 후보 두 개 이상에 쓰지 않았다.

## 검사와 남은 경고
- 5개 모두 `tools.plan check --draft` 통과.
- p1(귀걸이), p3(벨트): 소품 slot 경고. 생성형 코디컷에서는 쓰지 않는 값이라 두었다.
- 색 옵션은 상품명과 후보 목록만 보고 정했다. 사진 확인 전이라 p2·p5 버건디 가방(마리백, 셀루나), p3 진청 데님, p2 아이보리 트위드, p4 그레이 스커트가 실제 옵션에 있는지는 고른 뒤 photo-checker 가 확인한다. 없으면 같은 카테고리 다른 상품으로 바꾼다.
- 코디컷 이미지(`tools.plan build`), 사진 확인, 문구는 만들지 않았다.
