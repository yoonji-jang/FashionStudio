# 참고 코디 (women)

핀터레스트, 패션 매거진, 인플루언서, 브랜드 룩북에서 사용자가 좋다고 고른 코디를 글로 옮긴 목록이다.
후보를 고를 때 **기준 코디**로 쓴다 (styling.md "따라 입기", 2026-10-13 사용자: "쇼핑몰 코디를 비슷하게 따라 하며 배우자").
- 벌마다 여기 코디나 쇼핑몰 착용컷 중 하나를 기준으로 정하고, 창고에서 칸마다 비슷한 상품(종류·색·핏)을 찾아 다시 만든다.
- 비슷한 상품이 없는 칸(가방·소품)은 어울리는 것으로 바꿔도 된다. 상의·하의·신발이 없으면 다른 코디를 고른다.
- 따라 했으면 그 벌의 `reason` 끝에 `(따라 함: 참고 7)` 처럼 번호를 적는다.
- **2026-10-13 부터 기준 코디는 `data/women/refs.json` 에 있다** (쇼핑몰 착용컷 사진 주소 + 칸별 종류·색, 매주 100벌쯤).
  이 파일의 1~62 는 사진이 없는 글이라 분위기 참고로만 보고 기준 코디로 쓰지 않는다.
- 줄무늬·래글런 겹침(예: 2·22·26번)은 styling.md "그대로 남기는 규칙"(래글런은 맨 바깥, 줄무늬는 겉에 한 장) 안에서만 따라 한다.
- 사진·페이지 원본은 저장소에 두지 않는다. 사용자가 새 참고 사진을 보내면 아래 형식으로 글만 덧붙인다 (번호는 이어서).
- 매주 주제를 정할 때 공개 코디 페이지를 웹 검색해 `## <날짜> 웹 검색 (자동)` 절을 더하고, 오래된 자동 절은 지운다
  (plan-themes "참고 코디 모으기", profile `themes.ref_search`).

형식: 번호. **한 줄 이름**: 아이템 (색) / 한 끗 / 실루엣. 출처 종류, 날짜 사진: <사진 주소>
