# 2026-10-04 (일요일) 코디 후보 (women)

## 주제
이슬비 오는 일요일, 매트한 소재와 두 색 조합으로 가을 나들이 (상황).
서울 약한 이슬비, 14~23°C, 강수확률 66%. 물에 약한 스웨이드는 피하고, 트렌치·트위드·레더 같은 겉옷과 어두운 하의로 실용 있게 짰다.
`COLLECT` 는 비어 있어 새로 수집하지 않고 창고 상품만 썼다.

## 후보 (`picks/p1.yaml` 한 파일에 여덟 벌: 앞 6벌 + 예비 2벌)
1. 하프 트렌치(베이지) + 니트 베스트(브라운) 밖으로 스트라이프 셔츠(하늘색) 깃·소매, 하늘색 쁘띠 스카프. 브라운 + 하늘색
2. 부클 니트 베스트(아이보리) + 스트라이프 셔츠(네이비) + 와이드 데님, 가죽 벨트·볼캡. 데님 + 브라운 가죽
3. 트위드 자켓(차콜) + 새틴 미디스커트(올리브) + 헨리넥(네이비), 레드 쁘띠 스카프. 네이비 + 올리브, 소재 대비
4. 모헤어 가디건(퍼플) + 블라우스 깃 + 핀스트라이프 슬랙스(그레이), 시계·안경. 퍼플 + 그레이
5. 레더 재킷(블랙) + 시스루 셔츠 + 체크 미디스커트(버건디) + 니삭스. 블랙 + 버건디
6. 헤어리 뷔스티에(버건디) + 레이스 블라우스(아이보리) + 블랙 와이드 슬랙스, 골드 벨트·귀걸이. 버건디 + 아이보리
7. (예비) 레더 블루종(브라운) + 와이드 데님 + 스니커즈·볼캡. 데님 + 브라운 가죽, 스포티 믹스
8. (예비) 오프숄더 셔츠카라 니트(버터옐로) + 롱 플리츠(그레이) + 앵클부츠. 버터옐로 + 그레이

옷(아우터·상의·하의)은 벌마다 다른 상품이고, 가방·신발·소품도 겹치지 않게 골랐다.

## 확인할 것
- 검사(`tools.plan check --draft`) 통과. 남은 경고는 소품의 slot/wear_with 안내뿐이고 예전 누끼 방식용이라 생성형 코디컷에는 영향이 없다.
- 상품명에 색이 없는 것은 `color` 에 쓰려는 색만 적었다. 고른 뒤 사진 확인에서 그 색 옵션이 있는지 봐야 한다 (없으면 같은 카테고리 비슷한 상품으로 교체).
  특히 6번 헤어리 뷔스티에(버건디), 8번 오프숄더 니트(버터옐로), 3번 새틴 스커트(올리브), 4번 모헤어 가디건(퍼플).
- 2번 니트 베스트는 단추 없는 풀오버로 적었다 (10-03 피드백: 니트 조끼 단추 없애기). 사진에 단추가 있으면 확인.
- 한 벌짜리 상품은 모두 `reason` 으로 차이를 적었고 `text`, `photo`, `cutout_photo` 는 비워 두었다.
- 코디컷 이미지는 만들지 않았다. 게시·커밋·푸시·외부 전송 없음.
