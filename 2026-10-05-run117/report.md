# 2026-10-05 코디 후보 (women)

주제: 이슬비 오는 출근길, 버건디 베스트에 아이보리 셔츠 깃 빼기 (상황). 월요일, 흐림 14~18°C, 강수확률 88%라
어두운 하의와 가죽 신발로 실용을 챙기고 니트 베스트로 겹 수를 맞춤.

여러 벌 게시물이라 `picks/p1.yaml` 하나에 8벌(앞 6벌 + 예비 2벌). 1번이 가장 안전한 조합.

|---|---|---|
| 1 | 그레이 트위드 자켓 + 버건디 베스트 | 버건디 + 아이보리 |
| 2 | 블랙 트위드 자켓 + 네이비 베스트·스트라이프 셔츠 | 네이비 + 화이트 스트라이프 |
| 3 | 브라운 하프코트 + 빈티지 데님 | 브라운 + 하늘색 |
| 4 | 퍼플 뷔스티에 베스트 + 그레이 체크 미디스커트 (아우터 없음) | 퍼플 + 그레이 |
| 5 | 차콜 크롭 자켓 + 버터옐로 헨리넥 | 버터옐로 + 그레이 |
| 6 | 블랙 레더 하프자켓 + 새틴 맥시스커트 | 브라운 + 블랙 |
| 7 (예비) | 베이지 하프 트렌치 + 올리브 플리츠 스커트 | 네이비 + 올리브 |
| 8 (예비) | 레드 뷔스티에 니트 + 블랙 버뮤다 + 롱부츠 (아우터 없음) | 레드 + 무채색 |

- 옷은 벌마다 다른 상품, 가방은 `153923114`(1·7)과 `130117567`(5·8)만 두 벌씩 같이 씀.
- 상품 이름에 색이 없어 `color` 는 의도한 색이다 (창고 `colors` 가 비어 있음). 고른 뒤 사진 확인에서 맞는 색 사진이 없으면 같은 카테고리로 바뀔 수 있다.
  특히 2·7·8번의 셔츠·베스트·스커트 색(스트라이프 색, 올리브, 레드)을 사진으로 확인해야 한다.
- 비 오는 날이라 스웨이드 대신 가죽·합성 소재 신발·가방 위주.
