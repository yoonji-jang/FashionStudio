# 폰트

제목 합성(`tools.overlay`)이 프로필 `visual.font`, `visual.logo_font` 에 적힌 파일을 이 폴더에서 읽는다.

| 파일 | 출처 | 라이선스 |
|---|---|---|
| `Pretendard-Bold.otf` | [Pretendard](https://github.com/orioncactus/pretendard) 1.3.9 | SIL Open Font License 1.1 (`OFL.txt`), 상업 이용 가능 |

다른 폰트를 쓰려면 파일을 여기에 넣고 프로필의 `font` 를 그 파일명으로 바꾼다.
상업 이용이 가능한 라이선스인지 확인하고, 라이선스 파일도 함께 둔다.
