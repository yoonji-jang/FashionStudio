# 2026-10-14 코디 후보 (women)

주제: [팁] 블랙 코디에 컬러 한 방울 얹는 법 (무채색 바탕 + 버건디·플럼 한 색).
후보는 `picks/p1.yaml` 하나에 5벌(`looks.min`). 상품 창고가 기준 코디를 8점 이상으로 맞추지 못해 6+2벌을 채우지 못했다.

## 보낼 벌 (점수 순)
1. 블랙 레더 블레이저 + 크림 셔츠 + 카프리 팬츠 + 버건디 스카프 [7] (참고 109). 참고의 스트랩 힐 자리는 발레리나 플랫으로 바꿈
2. 플럼 브이넥 반팔 니트 + 블랙 울 미니 + 롱부츠 [6] (참고 132). 니트가 참고(버건디)보다 보랏빛
3. 버건디 오픈카라 셔츠 + 블랙 와이드 슬랙스 [6] (참고 134). 상품 사진에 버건디가 거의 없어 색 확인 필요
4. 와인 라운드 가디건 + 화이트 나시 + 블랙 와이드 슬랙스 [6] (참고 137). 참고는 퍼플, 상품은 더 붉은 와인
5. 블랙 헨리넥 니트 + 랩 스커트 팬츠 + 니삭스 + 플랫폼 로퍼 [5] (참고 129). 참고의 핀스트라이프 셔츠 칸은 못 맞춰 뺌

8점 미만이라 점수 낮은 순으로 `looks.min` 을 채웠다. 사람이 1번을 우선 보는 것이 안전하다.

## 뺀 벌
- 참고 106 (블랙 트렌치): 창고 트렌치가 사진상 모브 핑크 [점수 없이 제외, 칸 색 계열 다름]
- 참고 117 (블랙 롱코트 + 롱스커트): 코트 사진이 회색, 니트 티도 회색 [제외]
- 참고 136 (와인 블루종): 블루종이 갈색·블랙 벨벳 레더(칼라 있음), 슬라우치 부츠가 베이지 [제외]
- 참고 102 (크림 셔츠 + 스커트 팬츠): 셔츠 사진이 블루·블랙, 가방이 브라운 [5 이하]
- 참고 112·121·130·120·124 등은 속옷 이너(홀터)가 세트 상품뿐이거나 칸 상품이 창고에 없어 짜지 않음
