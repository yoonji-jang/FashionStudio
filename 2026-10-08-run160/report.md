# 2026-10-08 코디 후보 (여러 벌 게시물, p1.yaml 에 8벌 = 6벌 + 예비 2벌)

주제: [팁] 셔츠 깃 빼 입는 니트 레이어드 TIP (목요일, 맑음 12~22°C, 일교차)
지난 후보(`previous/p1.yaml`)는 셔츠 + 니트 베스트 여섯 벌이라 겹치지 않게 새로 짰다. 상품도 모두 바꿨다.
셔츠·베스트는 한 벌씩만 두고 맨투맨, 헨리넥, 래글런, 가디건으로 섞었다.

1. 블랙 니트 베스트 + 아이보리 스트라이프 셔츠(깃 빼기) + 베이지 조거 + 골드 링귀걸이 (한 끗: 깃·밑단)
2. 그레이 딥브이 헨리넥 니트 + 브라운 레이스 나시(대비색) + 연청 부츠컷 + 롱 펜던트 (몸에 붙는 상의 + 부츠컷)
3. 네이비 V넥 맨투맨 + 스트라이프 티 밑단 + 브라운 스웨이드 미니 + 롱부츠 + 안경 (큰 상의 + 짧은 하의)
4. 그레이 나그랑 스트라이프 티 + 버건디 가디건 어깨에 두르기 + 아이보리 새틴 롱스커트 + 니삭스
5. 네이비 오프숄더 셔츠카라 니트 + 진청 세미와이드 데님 + 실버 목걸이 (셔츠 깃이 이미 달린 니트)
6. 브라운 레더 블루종 + 그레이 래글런 티 + 차콜 핀스트라이프 슬랙스 + 벨트
7. 스틸 블루 골지 가디건 세트 + 그레이 헨리넥 밑단 + 그레이 케이블 니트 쇼츠 + 롱부츠 + 크림 비니 (참고 5)
8. 블랙 레더 재킷 + 홀터 탑 + 블랙 미니 + 롱 목걸이 (올블랙, 예비)

참고 코디 응용: 1~7번은 ref_looks 의 1, 2, 3, 5, 8 등을 색·아이템을 바꿔 응용했다 (벌별 reason 에는 7번만 번호 표기).

## 바꾼 것 (쇼핑몰 사진 확인)
- 올리브 베스트 후보(펌킨 조끼)는 사진에 올리브가 없어 다른 베스트로 바꿨는데, 새 베스트도 사진에는 블랙만 있어 1번을 블랙 베스트로 했다.
  주제의 올리브 색은 이번 후보에 들어가지 못했다.
- 사진 색에 맞춰 고친 것: 2번 니트 그레이 + 브라운 나시, 3번 티 아이보리·스커트 브라운·부츠 다크브라운, 4번 가디건 버건디·스커트 아이보리·니삭스 그레이,
  5번 니트 네이비(나시는 빼고, 니트에 셔츠 깃이 달려 있음), 6번 로퍼 모카, 7번 세트 스틸 블루·비니 크림.
- 사진 속 색을 확인하지 못한 것은 이름과 사진으로 가장 가까운 색을 적었다 (3번 토트, 4번 메리제인 스니커즈 등).
