# 후보 고치기 (2026-11-07, run446)

- 1번: 참고 821 로 통째로 새로 짬. 타이 블라우스(171437031) + 머메이드 롱스커트(109044216, 블랙) + 메리제인 펌프스 + 니치 숄더백 + 실버 귀걸이. 창고에 그레이 시스루 블라우스가 없어 쇼핑몰 사진은 화이트에 가깝다 (색은 그레이로 적음).
- 2번: 트위드 셋업 자켓(160260257)과 셋업 미니스커트(160190343, 같은 브랜드 셋업)로 교체, 신발은 오버니 부츠(131281211). 셋업 자켓 사진은 아이보리·핑크·라벤더뿐이라 블랙이 아님. 같은 원단 스커트 단품이 없어 같은 브랜드 셋업 스커트로 맞춤.
- 3번: 참고 822 로 통째로 새로 짬. 트위드 2IN1 미니 원피스(171708608) + 메리제인 슬링백 + 위빙 숄더백 + 귀걸이·진주 목걸이. 창고에 금색 단추·흰 프릴 원피스가 없어 비슷한 네이비 트위드 원피스(리본 장식)로 맞춤.
- 4번: 울 블레이저 → 정핏 울 자켓(171067679), 니트 뷔스티에 → 딥브이넥 니트(171229702). 흰 셔츠는 이너로 그대로.
- 5번: 골지 가디건 → 얇은 타이 블라우스(171217797), 니트 뷔스티에 → 기장 긴 뷔스티에(171826596, 브라운 색은 사진으로 확인 못 함).
- 6번: 슬라우치 롱부츠 → 앞코 뾰족한 하이힐 펌프스(145695732). 창고에 포인티드 펌프스는 없고 스틸레토 슬링백이 가장 가까움.
- 7번: 모직 싱글자켓 → 울 싱글 자켓(166196984). 브라운 색은 사진으로 확인 못 함 (사진은 아이보리·그레이·블랙).
- 8번: 테일러드 자켓 → 울 크롭 자켓(168548471), 니하이 부츠 → 오버니 부츠(146939237).
