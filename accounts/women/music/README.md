# 릴스 배경 음악

여기에 넣은 음원(mp3, m4a, aac, wav, ogg)을 릴스에 날짜마다 한 곡씩 돌려 씁니다 (`tools.reels`).
파일이 없으면 소리 없는 릴스가 됩니다.

- **상업 이용이 허락된 음원만** 넣으세요. 유행 가요·드라마 OST 처럼 권리가 있는 곡은 인스타가 음소거하거나 게시물을 내릴 수 있어요.
- 인스타 앱의 음악 라이브러리는 게시 API 로 넣을 수 없어서, 파일을 영상에 직접 넣습니다.
