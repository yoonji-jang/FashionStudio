# 참고 코디 (women)

핀터레스트, 패션 매거진, 인플루언서, 브랜드 룩북에서 사용자가 좋다고 고른 코디를 글로 옮긴 목록이다.
후보를 고를 때 **참고만** 한다 (2026-10-07 사용자: "100% 따라 할 필요는 없어, 참고 정도만, 자율성을 남겨 줘").
- 마음에 드는 조합이 있으면 창고에서 비슷한 상품(종류·색·핏)을 찾아 응용해도 된다. 색이나 아이템 하나를 바꾸는 것도 좋다.
- 꼭 써야 하는 건 아니다. 여섯 벌 중 몇 벌을 여기서 가져올지는 정하지 않는다. 나머지는 styling.md 대로 자유롭게 고른다.
- 응용했으면 그 벌의 `reason` 끝에 `(참고 7)` 처럼 번호를 적는다.
- 사진·페이지 원본은 저장소에 두지 않는다. 사용자가 새 참고 사진을 보내면 아래 형식으로 글만 덧붙인다 (번호는 이어서).
- 매주 주제를 정할 때 공개 코디 페이지를 웹 검색해 `## <날짜> 웹 검색 (자동)` 절을 더하고, 오래된 자동 절은 지운다
  (plan-themes "참고 코디 모으기", profile `themes.ref_search`).

형식: 번호. **한 줄 이름**: 아이템 (색) / 한 끗 / 실루엣. 출처 종류, 날짜
