# 2026-10-14 코디 후보 (outfit-candidates)

주제: [팁] 블랙 코디에 컬러 한 방울 얹는 법, 이너와 소품으로 포인트 TIP (무채색 바탕에 버건디·플럼·애쉬 블루 중 한 색)
파일: `out/2026-10-14/picks/p1.yaml` (여러 벌 게시물, 8벌 = looks.count 6 + spare 2). 코디컷 이미지는 만들지 않음.

## 벌 목록 (앞이 가장 자신 있는 벌)
1. 블랙 골지 니트 + 블랙 부츠컷 + 로퍼, 버건디 루비백이 포인트 (9점)
2. 퍼플 딥브이 니트 + 그레이 레이스 나시 이너 + 블랙 치마바지 + 니하이 롱부츠 (9점)
3. 블랙 하이넥 레더 재킷 + 퍼플 헨리넥 + 블랙 와이드 팬츠 + 워커, 그레이 스카프 (8점)
4. 블랙 울 하프코트 + 그레이 골지 니트 + 블랙 부츠컷 + 슬링백 (8점)
5. 플럼 보트넥 니트 + 블랙 플리츠 롱스커트 + 메리제인 플랫 + 블랙 삭스 (8점)
6. 차콜 헨리넥 + 블랙 버뮤다 + 삼바 메리제인 + 오버 니삭스 (8점, 컬러 한 방울 없음)
7. 애쉬 블루 맨투맨 + 차콜 스웻팬츠 + 메리제인 스니커즈 (8점)
8. 블랙 크롭 레더 자켓 + 그레이 헨리넥 밑단 + 랩 스커트 팬츠 + 롱부츠 (8점)

## 뺀 벌 (점수, 이유)
- 후드집업 벌 (6점): 후드집업이 네이비에 분홍 리본 자수라 이너 규칙·색 모두 어긋남
- 스웨트셔츠 + 니트 쇼츠 벌 (5점): 스웨트셔츠에 캐릭터 그래픽, 쇼츠는 블랙에 나이키 로고
- 래글런 맨투맨 + 스웻팬츠 벌 (7점): 맨투맨 뒷면에 큰 자수
- 크롭 레더 + 줄무늬 버튼 티 벌 (7점): 줄무늬 티를 안에 받치게 돼 styling.md 위반
- 모헤어 가디건 벌: 색(플럼)이 상품에 없고 사진 확인도 못 함

## 사진 확인으로 고친 것
- 상세 사진이 짐작과 달라 색을 고침: 딥브이 니트(블랙 → 퍼플), 보트넥 니트(차콜 → 플럼), 하프코트(차콜 → 블랙), 헨리넥(차콜 → 퍼플·그레이), 밴딩 팬츠(차콜 → 블랙)
- 스웨이드 로퍼(탄·핑크뿐), 베이지 캡소매 니트(나시 아님), 새틴 롱스커트(블랙 옵션 없음)는 후보에서 뺌
- 상세 사진 속 이너: 딥브이 니트 착용컷에 흰 이너·레이스 나시가 보여 2번 벌에 그레이 레이스 나시를 받침

## 남은 점
- 6번 벌은 컬러 한 방울이 없다 (주제 "몇 벌에만 적용"이라 둠). 마음에 안 들면 예비 순서로 돌려도 된다
- 상품 창고에 블랙 무지 나시가 없어 이너는 그레이 레이스 나시 하나뿐. 이너를 쓰는 벌은 2번 벌만 남음
- 버건디 가방은 루비백 한 개만 상세 사진으로 확인됨 (클리프·포코 등은 블랙만 확인)
- 같은 옷이 두 벌에 들어간 상품: 골지 헨리넥(3·8번), 쇄골트임 골지 니트(1·4번)
- `tools.plan check --draft` 통과. 경고는 소품 slot 지정 권고뿐 (후보 단계라 그대로 둠)
- 이 확인은 쇼핑몰 착용컷 기준이라 실제 색상 옵션 이름은 고른 뒤 사진 확인에서 다시 본다
