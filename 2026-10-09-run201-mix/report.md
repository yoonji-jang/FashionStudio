# 2026-10-09 퇴근하고 바로 약속일 때 / 블랙에 버건디 한 방울 공식

- 주제: [상황] 퇴근 후 약속엔 새틴 스커트에 레더 한 방울
- 조합: 퇴근 후 약속룩을 버건디 새틴과 블랙 레더, 차콜 톤온톤, 데님 캐주얼까지 색과 실루엣을 바꿔 여섯 가지로
- 코디 6벌, 슬라이드 8장
- 검수: 1번 c2 7점 (failed) / 2번 c2 8점 (passed) / 3번 c2 8점 (passed) / 4번 c1 8점 (passed) / 5번 c1 6점 (failed) / 6번 c2 8점 (passed)
  - 1번 벌: 그레이 보트넥 니트가 주인공, 흰 레이스 나시 끈을 보이게 하고 차콜 맥시 울스커트에 로퍼와 그레이 삭스로
  - 2번 벌: 아이보리 오프숄더 니트가 주인공, 버건디 가디건을 어깨에 두르고 블랙 미니스커트에 롱부츠로
  - 3번 벌: 그레이 벌룬 맨투맨이 주인공, 그레이 미니 스커트 쇼츠와 블랙 롱부츠로 다리를 길게
  - 4번 벌: 블랙 크롭 레더자켓이 주인공, 블랙 새틴 미디 스커트에 버건디 백으로 퇴근 후 저녁 분위기
  - 5번 벌: 버건디 홀터 슬림 니트가 주인공, 블랙 새틴 맥시 스커트와 메리제인으로 어깨를 드러낸 저녁 약속
  - 6번 벌: 블랙 홀터넥 슬림 티가 주인공, 블랙 와이드 팬츠와 앵클부츠로 올블랙의 슬림한 실루엣
- 참고: 코디컷 생성 비용 약 $1.34

## 피드백 반영 (3회)

- **3장 2번 벌 (아이보리 니트 + 미니 스커트)**: 원문 "부츠 한 켤레 평행·가운데, 밑단 곧게, 허리 턱 주름·앞 솔기 금지, 가디건이 보트넥 목선 가리지 않게".
  바꾼 값: 스커트 desc(허리 턱 주름·앞 솔기 없음), styling, `cover:` 삭제. 검수: c1 6점 → c2 8점 통과, feedback_ok false.
  허리 턱 주름은 없어졌지만 부츠가 아직 V자로 벌어지고 가디건이 어깨선을 덮으며 니트 옆트임 밑단이 사라짐. 사람 확인 권장.
- **4장 3번 벌 (맨투맨 + 스커트 쇼츠)**: 원문 "쇼츠·부츠 더 아래, 나시·맨투맨이 허리 안 덮게, 허리밴드·벨트고리·단추 보이게, 부츠 글자 자리 피하기".
  바꾼 값: styling(나시 밑단 숨김, 쇼츠·부츠 더 아래), `cover:` 삭제. 검수: c1 7점 → c2 8점 통과, feedback_ok false.
  허리 디자인은 다 보이고 부츠도 내려갔으나 부츠 왼쪽 가장자리가 글자 자리에 조금 걸침, 맨투맨이 원본보다 짧아짐, 스커트 쇼츠 앞 주름이 큼.
- **5장 4번 벌 (레더 자켓 + 새틴 미디 스커트)**: 원문 "치마 무릎 기장 48cm·H라인, 종아리·A라인 금지, 광택·볼륨·슬링백 유지, 헨리넥 단추 3개".
  해석: 실측 밑단 60→50cm 로 좁혀 A라인 방지 (원본 실측값과 다름, 코디컷 안내용). 바꾼 값: 스커트 `size`, styling, `cover:` 삭제.
  검수: c1 8점 통과, feedback_ok false (단추가 4개쯤으로 보여 3개 확인 안 됨, 가방 손잡이가 소매에 닿음). 기장·H라인·광택은 반영.
- **6장 5번 벌 (홀터 니트 + 새틴 맥시 스커트)**: 원문 "숫자·글자 금지, 1자 롱 새틴·엉덩이 볼륨·세로 주름, 오프숄더·홀터 끈 유지, 메리제인 나란히".
  바꾼 값: styling, `cover:` 삭제. 검수: c1 6점(스커트 A라인·납작, 0점 항목 있음) → c2 시도(메리제인에 브랜드 글자, clean 0)로 통과 못 함.
  도구가 채택한 c1 6점으로 사람 확인 필요. 숫자는 사라졌고 오프숄더·홀터는 유지.
- **7장 6번 벌 (홀터 슬림 티 + 와이드 팬츠)**: 원문 "바지 워시드 블랙, 카고 플랩 주머니, 통 안 좁아지게 발목까지 길게".
  바꾼 값: 바지 desc(카고 플랩 주머니·어두운 워시드 블랙), styling, `cover:` 삭제. 검수: c1 5점 → c2 8점 통과, feedback_ok true.
  남은 점: 무릎에 원본에 없는 턱 주름, 밑단 쪽 통이 조금 좁아짐, 가방이 글자 자리에 걸침.
- **1장 표지**: 요청 없음. 그러나 6번 벌을 다시 그리면서 콜라주 표지를 새로 만들지 못해(옷 오려 내기 실패) 1번 벌 코디컷 표지로 바뀜. 지난 콜라주 표지가 필요하면 사람이 확인.
- 1번 벌·댓글 안내 장은 그대로 둠 (`cover:` 유지).
- 남은 문제: 5번 벌 검수 미통과 (사람 확인), 2·3번 벌은 통과했지만 feedback_ok false, 1번 벌 검수 7점 (지난 그대로, 사람 확인).
  `tools.plan check` 경고(5·6번 벌 파인 목선 이너)는 피드백이 어깨 노출·홀터 디자인을 요구해 그대로 둠.
