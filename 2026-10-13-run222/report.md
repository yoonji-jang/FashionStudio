# 2026-10-13 코디 후보 (women, outfit-candidates)

- 주제: [아이템] 코듀로이 자켓에 가을 니트와 롱부츠, 질감으로 멋 내기 (브라운·카키·베이지). 날씨 예보는 강한 비 15~20°C 라 레더·나일론 가방과 아우터도 섞었다.
- 지난 후보(`previous/`)가 있어 주인공 상품과 색 조합이 겹치지 않게 새로 짰다 (스키마 한도로 최대 9벌, 8벌만 보냄).

## 벌 (앞이 가장 자신 있는 벌)
1. 브라운 코듀로이 노카라 자켓 + 그레이 헨리넥 티 + 플레어 데님 (브라운·데님) [9]
2. 베이지 코듀로이 하프 자켓 + 아이보리 랩 니트 + 브라운 랩 롱스커트 [8]
3. 브라운 코듀로이 블레이저 + 그레이 맨투맨 + 와이드 데님 [8]
4. 브라운 스웨이드 카라 자켓 + 그레이 헨리넥 니트 + 아이보리 새틴 롱스커트 [8]
5. 블랙 하이넥 레더 재킷 + 그레이 U헨리넥 티 + 부츠컷 데님 + 볼캡 [8]
6. 차콜 롱코트 + 블랙 골지 니트 + 차콜 플리츠 롱스커트 (톤온톤) [8]
7. 브라운 크롭 스웨이드 자켓 + 그레이 맨투맨 + 스웨이드 미니 + 롱부츠 (실루엣 대비) [8]
8. 블랙 크롭 레더 자켓 + 그레이 니트 베스트 + 부츠컷 데님 [7, 8점 미만이지만 예비 자리 채우려 남김]

## 상세페이지 착용컷 확인
- 색 옵션이 사진과 다른 것은 고침 (헨리넥 티는 아이보리 없음 → 그레이, 하프 자켓 카키 → 베이지, 새틴 스커트 브라운 → 아이보리, 매트레더 블루종은 브라운이라 뺌).
- 피그먼트 스웨트(캐릭터 프린트)는 무지가 아니라 뺌. 딥브이 맨투맨은 이너 없이 못 써서 뺌.

## 빠진 벌
- 브라운 매트레더 블루종 + 카고 (점수 7, 색 계열 4개 경고)
- 아이보리 헨리넥 니트 + 스웨이드 자켓 조합 (헨리넥이 6벌에 몰려 상의 다양성 위해 교체)

## 남은 경고
- 하의 '워싱' 이름이 4벌 (1·3·5 + 부츠컷). 모두 다른 데님이라 그대로 둠.
- 8번 벌은 7점이라 문제 시 뺄 후보. 소품 있는 벌은 1·2·3·4·5·6·7 로 4벌 이상.
- `tools.plan check --draft` 오류 없음. 코디컷 생성(build)·게시·외부 전송은 하지 않음.
