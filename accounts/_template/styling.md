# 코디 기준

코디를 고르는 스킬(pick-outfit, outfit-candidates, plan-themes)이 이 파일을 따른다.
숫자·목록(포인트 말, 가격대, 수집 검색어)은 `profile.yaml` 의 `style`, `product_source` 에 둔다.

## 목표
(이 계정 코디가 주는 느낌을 한두 문장으로)

## 벌마다 지키는 것
1. 센스 포인트 (레이어링, 소재 대비, 패턴, 소품, 실루엣 대비 중 몇 개)
2. 색 조합
3. 소품 개수
4. 피할 것

## 레이어드 코디컷 적는 법
- 상의 두 개를 겹치면 안에 입는 상의에 `wear_with: 상의` (profile `outfit_image.layer_styling` 으로 입힘)
- 다른 방법은 벌의 `styling` 에 영어로
