# 코디 후보 (women, 2026-10-31 토)

## 주제
할로윈 약속룩, 블랙에 버건디·레더 한 끗으로 어둡게 멋 내기 (컬러무드). 코스튬 대신 소재와 어두운 톤으로 분위기를 낸다.
날씨 예보는 가져오지 못했다 (open-meteo 400 오류), 가을 기준으로 짰다.

## 후보 12벌 (`picks/p1.yaml`, 앞 6벌이 기본, 뒤 6벌 예비)
1. 블랙 하이넥 레더 재킷 + 블랙 헨리넥 티 + 블랙 플리츠 롱스커트 (올블랙, 참고 68) [9]
2. 브라운 스웨이드 재킷 + 화이트 레이스 나시 + 연청 부츠컷 + 롱부츠 (참고 70) [8]
3. 버건디 워크 자켓 + 화이트 나시 + 중청 와이드 데님 + 워커부츠 (참고 74) [8]
4. 네이비 모헤어 가디건 + 레이스 나시 + 블랙 새틴 미디 + 메리제인 (참고 32) [8]
5. 블랙 크롭 레더 + 그레이 헨리넥 니트 + 차콜 핀스트라이프 + 롱부츠 + 벨트 (참고 78) [9]
6. 브라운 스웨이드 바이커 + 아이보리 부클 베스트 + 브라운 새틴 롱스커트 (참고 50) [8]
7. 차콜브라운 크롭 자켓 + 블랙 맨투맨 + 진청 슬림 부츠컷 + 로퍼 + 볼캡 (참고 64) [8]
8. 아이보리 보트넥 니트 + 블랙 미니 + 슬라우치 롱부츠 + 버건디 숄더백 (참고 80) [8]
9. 블랙 라이더 자켓 + 그레이 헨리넥 + 베이지 와이드 슬랙스 + 로퍼 (참고 65) [8]
10. 블랙 트위드 자켓 + 오프숄더 카라 니트(안에 화이트 튜브탑) + 다크브라운 울 롱스커트 (참고 66) [8]
11. 베이지 코듀로이 하프 자켓 + 블랙 셔츠 + 진청 부츠컷 + 앵클부츠 (참고 74) [8]
12. 네이비 니트 베스트 + 화이트 셔츠 + 블랙 플로우 롱스커트 + 메리제인 (참고 77) [8]

## 점수와 뺀 벌
- 점수는 상세페이지 착용컷 확인표와 참고 코디를 나란히 본 어림 점수다. 8점 미만으로 뺀 벌은 따로 매기지 않았다
  (초안 12벌을 짠 뒤 색·상품 불일치를 고쳐 12벌 모두 8점 이상으로 두었고, 4벌 추가 초안은 만들지 않았다).
- 고친 것: 사진과 색이 달랐던 상품(연청 데님, 아이보리 보트넥·부클 베스트, 브라운 스커트·가방, 네이비 가디건·베스트 등)은
  사진에 맞춰 `color`·`desc` 를 바꿨다. 맞는 색 사진이 없던 레이스 블라우스, 블랙 데님은 다른 상품으로 바꿨다.
